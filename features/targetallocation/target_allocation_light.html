--- ## LLM CONTEXT & REFERENCE PROMPT ### Product Overview This is a **Target Allocation UI** for portfolio management. Users define desired allocations across different instrument types (BOND, COMMODITY, EQUITY, ETF, or custom types). The interface uses sliders instead of number inputs for intuitive adjustment and proportional rebalancing. ### Key Features 1. **Layout Order**: Chart visualization at top → Table with sliders → Save/Delete buttons at bottom 2. **Visual Themes**: Both light and dark themes with consistent functionality 3. **Slider-based Input**: 0-100% range per instrument type with real-time percentage display ### Interaction Logic - **Auto-Rebalancing**: When user adjusts one slider, unpinned instruments proportionally decrease/increase to maintain total - **Pin Functionality**: Users can "pin" (📌) instrument allocations to lock them. Pinned instruments won't change when other sliders move - **Total Constraint**: Sum must equal 100% for save button to enable - **Invalid State**: If total ≠ 100%, total indicator turns red with pulsing animation - **Reset**: Button resets all sliders to initial values - **Delete**: Always-visible button opens confirmation modal (better UX than hidden delete option) ### Data Structure Each instrument has: - `data-instrument`: Name (e.g., "BOND", "COMMODITY") - `value`: Current target percentage - `pinned` state: Boolean indicating if locked - Current allocation shown for reference ### Validation Rules 1. Save button disabled if total ≠ 100% 2. Total indicator is green (valid) at 100%, red (invalid) otherwise 3. User can exceed 100% by pinning everything, total displays warning state 4. All percentages rounded to nearest whole number for display ### Color System - Primary accent: Purple gradient (#9d4edd to #c77dff) - Valid state: Green (#16a34a) - Invalid state: Red (#dc2626) - Light theme: Soft gradients on white backgrounds - Dark theme: Glassmorphism with transparency and blur ### Add Instrument Feature Compact icon button (+) in bottom left with hover tooltip. Takes minimal space—useful but infrequently used so kept subtle. ### Future Considerations - Each instrument can have band ranges (min/max allowed values) - Chart updates in real-time as sliders change - Persistence of saved allocations - Support for custom instrument types - Undo/redo for slider adjustments
